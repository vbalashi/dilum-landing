# Editorial block inventory — prepared, not yet implemented

Owner: studio-navigation plan. Sources: Nikolai's 18 October reference review in
2000NL, https://www.thinkmill.com.au/blog and
https://maggieappleton.com/garden-history. This is a content/design contract for
a later specimen page, not an instruction to migrate CMS or invent illustrations.

| Block | Author controls | Display / reference | Next review |
| --- | --- | --- | --- |
| Article identity | title, summary, author, date, topic, language, related products | Thinkmill: clear byline, context and related work | Use real draft metadata |
| Body / headings | paragraphs, H2/H3, lists, emphasis, links | Shared Literata/Manrope hierarchy; Maggie's calm reading | EN/RU, light/dark |
| Figure | source, alt, caption, credit, text/wide/full width | Maggie illustration/caption; Distill width principle | Wait for owner's screenshots |
| Editorial aside | short author observation | Type/spacing or a restrained rule; avoid generic Note/Tip boxes | Not a quotation unless verbatim |
| Quotation | quotation and attribution | Distinct from author's own aside | Clear source |
| Contents | headings; optional enable | Maggie: collapsible left on wide screen, in flow on narrow | Short articles may omit |
| Note | stable id, body, source | Maggie: optional context near reference; inline fallback on mobile | Keyboard, tap, return to text |
| Link explanation | link + optional brief explanation | Maggie: supplemental preview, normal link still works | Never hover-only |
| Table | headings, cells, caption/source | Readable comparison | Narrow screen overflow local to table |
| Article end | author, related articles/product, crosspost URLs | Thinkmill: clear context and next step | No mandatory previous/next |

Authoring format remains open: normal Markdown for ordinary copy; custom block
syntax/editor must be chosen by a later write → preview → edit roundtrip.
Interactive charts and scrollytelling remain a later optional capability.
